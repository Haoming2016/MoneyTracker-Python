# MoneyTracker

## Installation

First, download or clone this project to your computer.

Make sure you have Python installed. Then install all required packages.

If you get an error that a package is missing, install it using pip.

Example:

```bash
pip install PySide6
pip install google-genai
```

## Setup Gemini API

To use the AI features in Money Tracker, open the file:

AI.py

Find the API key section and insert your own Google Gemini API key.

You need a Gemini API key for the AI functions to work.

## Start the Program

After setting up the API key, open the file:

__init__.py

Run this file to start Money Tracker.

## Troubleshooting

If you get an error like:

ModuleNotFoundError: No module named 'PySide6'

Install PySide6:

```bash
pip install PySide6
```

If you get an error about Google GenAI:

```bash
pip install google-genai
```

Make sure all required packages are installed and that your Gemini API key is correct.

## Requirements

- Python 3.10 or newer
- PySide6
- Google GenAI SDK
- Google Gemini API key

## About Money Tracker

Money Tracker is a Python application that helps you manage your money and transactions.

Enjoy using Money Tracker!
